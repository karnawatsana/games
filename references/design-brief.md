# The Daily 3 — Design Brief

## Visual Identity

The Daily 3 is a premium, playful, editorial-style social brain-game application.

The interface should look professionally art-directed, with the quality of a carefully designed consumer product.

## Design References

Study all three images in `references/design/` before implementing the UI.

Use them as inspiration, not templates to copy exactly.

Pay particular attention to:
- Bold, colorful modular cards
- Charcoal backgrounds and warm neutrals
- Large rounded corners
- Clean, expressive typography
- Generous whitespace
- Floating pill-shaped navigation
- Minimal visual clutter
- Strong color blocking
- Asymmetric but balanced compositions

## Typography

- **Inter:** Functional UI, buttons, navigation, scoreboards, labels.
- **Instrument Serif:** Editorial headings, expressive phrases, and surprise-game reveals.

## Brand Colors

- Charcoal: `#202120`
- Cream: `#F5F1E8`
- Lime: `#D3ED77`
- Yellow: `#FFD16A`
- Coral: `#F27B70`
- Mint: `#B7EADD`
- Sky Blue: `#B8CEEF`
- Lavender: `#A89CF0`

## Design Principles

1. Prioritize mobile-first layouts.
2. Use solid, expressive card backgrounds.
3. Avoid generic dashboard aesthetics.
4. Use glassmorphism sparingly.
5. Create thoughtful spacing and typographic hierarchy.
6. Ensure every screen feels consistent with the overall brand.
7. Prioritize both usability and visual polish.

The intended result should feel playful, intelligent, minimal, and memorable.

## Visual Quality Checks

After building each major screen, review its rendered appearance against the reference images.

Refine typography, spacing, color, and composition before considering the design complete.
